**SAH-in Aja!** is Indonesia's first AI-powered halal certification preparation platform built for the nation's 30+ million MSMEs. It provides **Vision AI assessment** of kitchen/production facilities, **smart document generation** for SJPH compliance, and a **guardrailed chatbot** for 24/7 halal certification guidance—running on a credit-based system that resets daily, optimized for low-end devices over 4G networks.

### Why it matters

- **Democratizes access**: Free tier with 3 assessments + 3 documents + 5 chats/day removes financial barrier for struggling UMKM
- **Vision AI democratization**: Upload 5 photos of kitchen, get audit-grade assessment in 2 minutes (model: Claude Sonnet 4.5)
- **Smart document generation**: 5 SJPH templates (SOP, supplier agreements, traceability forms) auto-populated from business data
- **Guardrails-first chatbot**: LLM-based topic classification prevents misuse; keyword filters block harmful content
- **Credit system**: Daily reset at UTC+7 (7 AM WIB) with promo code support for bonus credits
- **Low-end optimized**: Runs smooth on Samsung A03, Redmi 9A, Oppo A16 (2-3GB RAM, Android 11+)

### How it works (brief)

1. **Login seamlessly**: Magic link + Google OAuth + GitHub OAuth via Convex Auth
2. **Siap Halal**: Upload 5 kitchen photos → Vision AI (Claude Sonnet 4.5) scans for haram materials, contamination risks → Score 0-100 with actionable fixes
3. **Dokumen Halal**: Choose template → Fill business info → AI generates SJPH-compliant document → Export to DOCX
4. **Asisten Halal**: Chat with Claude Sonnet 4.5 (topic-classified) about BPJPH procedures, halal ingredients, audit prep
5. **Credit tracking**: Automatic daily reset with rollover protection via `user_daily_credits` table

### Stack

- **Frontend**: React 19 + TypeScript + Wouter (routing) + Motion (animations) + Tailwind CSS 4.0
- **Backend**: Convex (real-time DB + serverless functions, self-hosted via Docker)

### 1. Siap Halal: Vision AI Assessment

Upload up to **5 photos** of your kitchen, and Claude Sonnet 4.5 Vision analyzes it against **SJPH HAS 23000** standards.

**Analysis framework** (5 criteria, 100 points total):

1. **Bahan (Materials)** - 30 pts: No haram substances visible, proper halal labels, separate storage
2. **Fasilitas (Production Facility)** - 25 pts: Cleanliness, no cross-contamination, no pets
3. **Peralatan (Equipment)** - 20 pts: Clean equipment, no shared tools with haram materials
4. **Penyimpanan (Storage)** - 15 pts: Proper raw material separation, temperature control
5. **Dokumentasi (Documentation)** - 10 pts: Clear labels, organized inventory

### Vision AI Workflow

```typescript title: convex/analyzeHalal.ts
export const analyzeKitchen = action({
  args: {
    photoStorageIds: v.array(v.id("_storage"))
  },
  handler: async (ctx, args) => {
    const kolosal = createKolosalClient(apiKey);

    // Convert storage IDs → URLs → Base64 (Claude requires base64)
    const imageBase64List = await Promise.all(
      args.photoStorageIds.map(async (storageId) => {
        const url = await ctx.storage.getUrl(storageId);
        return urlToBase64(url); // Convex runtime-friendly
      })
    );

    const response = await kolosal.chat.completions.create({
      model: KOLOSAL_MODELS.VISION, // "global.anthropic.claude-sonnet-4-5-20250929-v1:0"
      messages: [
        {
          role: "system",
          content: SYSTEM_PROMPTS.HALAL_ASSESSMENT
        },
        {
          role: "user",
          content: [
            { type: "text", text: "Analisis foto area produksi/dapur:" },
            ...imageBase64List.map((base64) => ({
              type: "image_url",
              image_url: { url: base64 }
            }))
          ]
        }
      ],
      temperature: 0.3, // Low temperature for strict assessment
      max_tokens: 2000
    });

    // Parse structured JSON output
    const { score, findings, actionItems, summaryPoints } = JSON.parse(response.choices[0].message.content);
    return { score, findings, actionItems, summaryPoints, photoUrls };
  }
});
```

### Document Generation Architecture

The system uses **two-stage prompt engineering**:

1. **Template prompt** defining document structure
2. **Dynamic data injection** from user input

```typescript title: convex/generateDocument.ts
const TEMPLATE_PROMPTS: Record<string, string> = {
  sop_produksi: `Buat SOP Produksi Halal yang mencakup:\n1. Tujuan...\n2. Prosedur Pemilihan...\n...`,
  perjanjian_supplier: `Buat Surat Perjanjian Supplier...\n1. Para Pihak...\n...`,
  daftar_bahan: `Buat Daftar Bahan Baku...`,
  traceability: `Buat Form Traceability...`,
  komitmen_halal: `Buat Surat Komitmen...`
};

export const generateHalalDocument = action({
  args: {
    templateType: v.string(),
    businessInfo: v.object({ name, address, owner, productType }),
    ingredients: v.array(v.object({ name, supplier, halalStatus }))
  },
  handler: async (_ctx, args) => {
    const templatePrompt = TEMPLATE_PROMPTS[args.templateType];

    const userContent = `${templatePrompt}

DATA USAHA:

- Nama: ${args.businessInfo.name}
- Alamat: ${args.businessInfo.address}
- Pemilik: ${args.businessInfo.owner}
- Produk: ${args.businessInfo.productType}

DAFTAR BAHAN:
${args.ingredients.map((i) => `- ${i.name} (Supplier: ${i.supplier}, Status: ${i.halalStatus})`).join("\n")}`;

    const response = await fetch("https://api.kolosal.ai/v1/chat/completions", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.KOLOSAL_API_KEY}`,
        Accept: "application/json",
        "Content-Type": "application/json"
      },
      body: JSON.stringify({
        model: KOLOSAL_MODELS.TEXT,
        messages: [
          { role: "system", content: SYSTEM_PROMPTS.DOCUMENT_GENERATOR },
          { role: "user", content: userContent }
        ],
        temperature: 1.0, // Higher for creative document generation
        max_tokens: 4096
      })
    });

    const data = await response.json();
    return { content: data.choices[0].message.content }; // Plain text format
  }
});
```

**Why plain text, not markdown?**
DOCX generation requires clean, structured text. The frontend uses `docx` npm library to convert plain text → formatted Word documents:

```typescript title: src/features/dokumen-halal/hooks/useDocumentGenerator.ts
// Pseudo-code showing conversion logic
import { Document, Packer, Paragraph, TextRun } from "docx";
import { saveAs } from "file-saver";

const generateDocx = (plainText: string, templateType: string) => {
  // Split by lines, detect headings via patterns
  const lines = plainText.split("\n");
  const paragraphs = lines.map((line) => {
    if (line === line.toUpperCase()) {
      // All caps = title/heading
      return new Paragraph({
        children: [new TextRun({ text: line, bold: true, size: 28 })],
        heading: HeadingLevel.HEADING_1
      });
    } else if (/^\\d+\\./.test(line)) {
      // Numbered list (e.g., "1.", "2.")
      return new Paragraph({
        children: [new TextRun({ text: line })],
        numbering: { num: abstractNumId, level: 0 }
      });
    } else if (line.startsWith("- ")) {
      // Bullet list
      return new Paragraph({
        children: [new TextRun({ text: line.replace("- ", "") })],
        bullet: { level: 0 }
      });
    }
    // Default paragraph
    return new Paragraph(line);
  });

  const doc = new Document({ sections: [{ children: paragraphs }] });
  Packer.toBlob(doc).then((blob) => saveAs(blob, `${templateType}_${Date.now()}.docx`));
};
```

## 3. Asisten Halal: Guardrailed Chatbot with LLM-Based Classification

This is where most chatbots fail: they either allow everything (risky) or block too much (useless). SAH-in Aja! uses a **hybrid approach**:

### Layer 1: Keyword Filtering (Fast Block)

```typescript title: convex/consultHalal.ts
const BLOCKED_KEYWORDS = [
  "bunuh",
  "racun",
  "bom",
  "senjata",
  "narkoba",
  "drugs",
  "teror",
  "sex",
  "porn",
  "bokep",
  "telanjang",
  "mesum",
  "kafir",
  "benci",
  "serang",
  "hina",
  "rasis",
  "hack",
  "crack",
  "bajak",
  "penipuan"
];

function containsBlockedContent(message: string): boolean {
  return BLOCKED_KEYWORDS.some((keyword) => message.toLowerCase().includes(keyword));
}
```

### Layer 2: Greeting Bypass

Simple greetings don't need LLM classification (saves cost + latency):

```typescript
const ALLOWED_GREETINGS = ["halo", "hai", "hello", "selamat pagi", "assalamualaikum", "terima kasih", "makasih"];

function isGreeting(message: string): boolean {
  const words = message.toLowerCase().split(/\s+/);
  return words.length <= 4 && ALLOWED_GREETINGS.some((g) => message.includes(g));
}
```

### Layer 3: LLM-Based Topic Classification

For complex queries, use **Claude Sonnet 4.5** to determine if question is halal-related:

```typescript title: convex/consultHalal.ts
async function classifyTopicWithLLM(message: string, kolosal: Client) {
  const classificationPrompt = `Kamu adalah classifier untuk aplikasi "Asisten Halal".

KONTEKS PENTING: Karena ini Asisten Halal, pertanyaan AMBIGU harus diasumsikan terkait halal.
Contoh: "Apa saja dokumen yang diperlukan?" → TERKAIT (tentang dokumen sertifikasi halal)

Topik TERKAIT halal:

- Status halal/haram makanan, bahan masakan
- Sertifikasi halal, dokumen, persyaratan, biaya
- Bahan kritis (gelatin, emulsifier, alkohol)
- Produksi makanan, dapur, restoran, UMKM
- Audit halal, LPH, BPJPH, MUI, SJPH

Jawab dengan format JSON:
{"isHalalRelated": true/false, "reason": "alasan singkat"}

Pertanyaan: "${message}"`;

  const response = await kolosal.chat.completions.create({
    model: KOLOSAL_MODELS.TEXT,
    messages: [{ role: "user", content: classificationPrompt }],
    temperature: 0, // Deterministic
    max_tokens: 100
  });

  const result = JSON.parse(response.choices[0].message.content);
  return { isHalalRelated: result.isHalalRelated === true };
}
```

**Why this is smart:** False positives (allowing non-halal questions) are better than false negatives (blocking legitimate users). This respects the platform's purpose while maximizing utility.

### Chat Context Integration

The chatbot can reference user's scan history for personalized advice:

```typescript title: convex/consultHalal.ts
export const chat = action({
  args: {
    message: v.string(),
    conversationHistory: v.optional(v.array(...)),
    userContext: v.optional(v.object({
      halalScore: v.optional(v.number()),
      lastScanFindings: v.optional(v.array(v.string()))

    let contextPrompt = "";

    const messages = [
      {
        role: "system",
        content: SYSTEM_PROMPTS.HALAL_ASSISTANT + contextPrompt
      },
      ...args.conversationHistory,
      { role: "user", content: args.message }
    ];

    const response = await kolosal.chat.completions.create({
      model: KOLOSAL_MODELS.TEXT,
      messages,
      temperature: 0.7,
      max_tokens: 4096
    });

    return {
      response: response.choices[0].message.content,
      source: "llm",
      confidence: 0.7
    };
  }
});
```

## Credit System: Daily Reset with Rollover Protection

### The Business Logic

Each user gets daily credits (reset at 7 AM WIB / UTC+7). This balances:

- **Fairness**: Everyone gets same daily allocation
- **Abuse prevention**: Can't hoard credits
- **Engagement**: Daily return visits
- **Conversion funnel**: Heavy users can enter promo codes

**Credit allocation**:

- **Siap Halal**: 3 scans/day
- **Dokumen Halal**: 3 documents/day
- **Asisten Halal**: 5 chat sessions/day

### Database Schema

```typescript title: convex/schema.ts
export default defineSchema({
  // ... auth tables

  users: defineTable({
    // ... user fields
    credits: v.optional(v.number()), // Koin SAH (for future paid tier)
    tier: v.optional(
      v.union(
        v.literal("free"),
        v.literal("eceran"), // Tier 1: Small business
        v.literal("juragan") // Tier 2: Medium business
      )
    )
  }),

  // Critical: Tracks daily usage
  user_daily_credits: defineTable({
    userId: v.id("users"),
    date: v.string(), // Format: "2025-12-10" in UTC+7
    siapHalalCredits: v.number(),
    dokumenHalalCredits: v.number(),
    asistenHalalChats: v.number()
  })
    .index("by_user", ["userId"])
    .index("by_user_date", ["userId", "date"]),

  // Promo code support (managed via Convex dashboard)
  promo_codes: defineTable({
    code: v.string(), // e.g., "SAH2025", case-sensitive
    credits: v.number(), // Amount to add (e.g., 100)
    maxUsage: v.optional(v.number()),
    usageCount: v.number(),
    expiresAt: v.optional(v.number()),
    isActive: v.boolean()
  }).index("by_code", ["code"]),

  // Track promo usage per user
  promo_code_usages: defineTable({
    userId: v.id("users"),
    promoCodeId: v.id("promo_codes"),
    usedAt: v.number()
  })
    .index("by_user", ["userId"])
    .index("by_user_code", ["userId", "promoCodeId"])
});
```

### Credit Deduction Logic

```typescript title: convex/credits.ts (simplified)
export const deductCredit = internalMutation({
  args: {
    userId: v.id("users"),
    feature: v.union(v.literal("siapHalal"), v.literal("dokumenHalal"), v.literal("asistenHalal"))
  },
  handler: async (ctx, args) => {
    const today = new Date().toLocaleDateString("en-CA", {
      timeZone: "Asia/Jakarta"
    }); // "2025-12-10"

    // Get or create daily record
    let daily = await ctx.db
      .query("user_daily_credits")
      .withIndex("by_user_date", (q) => q.eq("userId", args.userId).eq("date", today))
      .first();

    if (!daily) {
      daily = await ctx.db.insert("user_daily_credits", {
        userId: args.userId,
        date: today,
        siapHalalCredits: 0,
        dokumenHalalCredits: 0,
        asistenHalalChats: 0
      });
    }

    // Check limits
    const limits = {
      siapHalal: 3,
      dokumenHalal: 3,
      asistenHalal: 5
    };

    const current = daily[`${args.feature}Credits`];
    if (current >= limits[args.feature]) {
      throw new Error("Kredit harian habis. Coba lagi besok jam 7 pagi!");
    }

    // Increment
    await ctx.db.patch(daily._id, {
      [`${args.feature}Credits`]: current + 1
    });

    return { success: true, remaining: limits[args.feature] - (current + 1) };
  }
});
```

### Promo Code System

Admin can generate promo codes via Convex dashboard. When user redeems:

1. Check `promo_codes.isActive` && `usageCount < maxUsage`
2. Verify user hasn't used it before (`promo_code_usages` table check)
3. Add credits to `user.credits` (for future paid tier)
4. Increment `promo_codes.usageCount`
5. Create `promo_code_usages` record

### Optimization Strategies

1. **Bundle size consciousness**
   - Lazy load features: `const SiapHalal = lazy(() => import('./features/siap-halal'))`
   - Code splitting by route
   - Tree-shake icon libraries (use `lucide-react` selectively)

2. **Image optimization**
   - WebP with AVIF fallbacks
   - `<picture>` element for responsive images
   - Lazy loading + intersection observer
   - Convex Storage serves optimized images:
     ```
     https://cloudflare-worker.convex.cloud/api/storage/...?format=auto&width=800
     ```

3. **Runtime performance**
   - React 19's automatic batching
   - Debounced inputs (300ms for search)
   - Memoized expensive components (`React.memo`)
   - Virtualized long lists (not needed yet; 20 items max)

4. **Network resilience**
   - Retry logic for failed AI calls (3 attempts, exponential backoff)
   - Offline detection with `navigator.onLine`
   - Graceful degradation: show cached results if offline
   - Loading states with skeletons (not spinners) for perceived speed

- **JWT security**: RS256 tokens, 1-hour expiry

## Lessons Learned & Best Practices

### AI Prompt Engineering is Everything

The difference between a useless AI and a great one is **prompt quality**. We iterated 20+ times:

**Version 1 (Bad)**:

```
Analyze kitchen photos for halal issues.
```

Result: "The kitchen looks clean. 8/10." ❌

**Version 10 (Good)**:

```
You are a halal auditor. Check for 5 criteria: Bahan, Fasilitas, Peralatan, Penyimpanan, Dokumentasi.
Output JSON: {score, findings[], actionItems[], summaryPoints[], overallMessage}.
Bahasa: Simple Indonesian, max 5 summary points, use ✅ and ⚠️ emojis.
Be strict but polite.
```

Result: "Dapurnya sudah cukup bersih Bu! Tinggal ganti kecap, insyaallah lulus."
✅

### Guardrails Must Be Balanced

- **Too strict**: Blocks legitimate users → low engagement
- **Too loose**: Abuse → platform banned by Kolosal
- **Solution**: Keyword filter (fast) + LLM classification (accurate) + greeting bypass (UX)

### Low-End Optimization is Non-Negotiable

- Test on real devices, not just Chrome DevTools
- Use Lighthouse Mobile (4G, 4x CPU throttling)
- Bundle size budget: 300KB gzipped max
- Image optimization: WebP, lazy load all

### Self-Hosting Trade-offs

**Pros**:

- Data sovereignty (critical for Indonesian regulations)
- Lower latency (20-50ms vs 200ms)
- Predictable costs
- Full control

**Cons**:

- DevOps overhead (monitoring, backups, security patches)
- No automatic scaling (need manual load balancing)
- SSL cert management (Caddy automates this)

For MVPs, Convex Cloud is fine. For production with >10K users, self-host.
